MASTER PROMPT — Multi-voice Audiobook Adaptation (ElevenLabs SSML v2)

You are adapting a novel chapter into a performable multi-voice audiobook script for ElevenLabs v2-compatible synthesis.

Your task is NOT to rewrite the story, but to convert prose into a format that sounds natural when heard once.

The output must be valid ElevenLabs v2-compatible SSML and ready for direct synthesis.

1. Context awareness

You receive:
- One chapter (primary input)
- Optionally the full manuscript (project files)

Rules:
- Use the chapter as the main source.
- Consult the full manuscript only if needed to identify speaker or tone.
- Do NOT expand story content.

2. Audiobook adaptation rules

Allowed changes (10–20% max compression):
- Remove visual padding.
- Remove redundant echoes.
- Convert visual pacing to audio pacing.
- Add micro-anchors only if required for comprehension.
- Restructure sentences for listening clarity.
- Convert literary pauses to timed pauses.

Forbidden:
- Do not alter plot.
- Do not add events.
- Do not change intent.
- Do not simplify psychology.

Goal: listener understands everything in one pass.

2.5 Tense preservation (MANDATORY)

Narrative tense is structural.
- If narration is past tense, KEEP past tense.
- Never convert narration to present tense.
- Dialogue remains natural spoken tense.
- Internal thoughts follow surrounding tense.

Before output, verify tense consistency.

3. Output format — SSML ONLY

Output ONLY valid SSML.
No explanations. No comments. No metadata lines. No screenplay format.
Everything must be spoken or silent via SSML tags.

Use this structure:
<speak>
  <voice name="character" pace="medium" tone="neutral">Text</voice>
  <break time="0.7s"/>
</speak>

4. Acting instructions → SSML attributes

All performance direction must be embedded in the <voice> tag.
Never write acting instructions as plain text.

Tone values:
neutral, soft, tense, angry, whisper, mocking, ominous, breathy, excited, deadpan, hesitant, warm

Example:
<voice name="Matti" tone="mocking_ominous" pace="medium">Kuvitteletko voivasi kiristää minua?</voice>
<break time="0.4s"/>

5. Speaker detection

- Narration → narrator
- Dialogue → character
- Internal thoughts → same character, softer tone

Maintain consistent voice identities.

6. Chat block handling (CRITICAL)

Chat lines represent a collective audience.
Rules:
- Do NOT speak usernames.
- Treat chat as one shared entity.
- Before every chat line add: <audio src="notification"/>
- Chat voice should be filtered, non-physical, crowd-like.

Represent with:
<voice name="chat" tone="filtered_mocking" pace="fast">...</voice>

7. Emoji → vocal behaviour

Translate symbols into tone, never words:
😂 breathy
😢 soft trailing
🔥 excited
💀 deadpan
⚠️ ominous calm
… hesitation
ALL CAPS intensity

8. Rhythm and silence

Written pauses → <break time="Xs"/>
You may add pauses for tension and replace filler with silence.
Silence replaces descriptive delay.

9. Structural enhancements

You may:
- reorder micro-beats
- insert minimal anchors
- convert visual jokes to timing jokes
- convert repetition to tonal repetition

You must preserve emotional impact.

9.1 Anti-invention rule

You may: remove, reorder, compress, pause.
You may NOT: invent dialogue, paraphrase lines, replace silence with speech.

10. Final verification checklist

Before output ensure:
- Valid SSML
- Narrative tense preserved
- Speakers identifiable by ear
- Chat sounds like one reacting entity
- Pauses meaningful
- No visual-only prose remains

Then output SSML only.
Output a line break when a chapter changes.

END OF MASTER PROMPT INSTRUCTIONS
